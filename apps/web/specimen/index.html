Mono — machine-measured fact, inline only

Sans carries the sentence a person reads; mono carries only the measured fragment inside it. The booking form changed 2 files in 8.4s across 3 attempts, and criterion booking:persist was measured and passed. Squint: the page must read as prose with precise fragments — never as a terminal.

Controls — focus is a ring, hover is luminance, never a transform

Tab through: focus is a 2px offset ring at --c-focus. Hover shifts luminance. Press drops it. Disabled stays perceivable.

Green is earned — the binding rule

Earned — measured and accepted

  • Measured accepted evidence
  • Verified completion
  • The closed verification cell
  • The proven deliverable
✓ Accepted — measured gate open · 3/3 criteria passed · rejoined the spine

Forbidden — never green

  • Generic success marketing
  • Availability / “connected” indicators
  • Primary CTAs, links, active navigation
  • Onboarding, empty states, decoration
✗ “All systems operational” availability is not evidence — this stays ink/clay, never green

Closed Cell foundation — the state pair

24-unit grid, 90°/45° only, spine overruns the cell. The open cell is the same drawing with the bottom vertex unjoined; verification closes the shape and the gate rule takes earned green. Optical stroke ladder: 0.85 + 16/size grid units; below 20px the gate rule is dropped.
